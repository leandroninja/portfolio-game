# Portfólio · Leandro Oliveira Moraes

Portfólio de Arquiteto Sênior DevOps & Multi-Cloud, feito como um jogo de plataforma em canvas.
HTML, CSS e JavaScript puros, sem dependências.

**Online:** https://leandroninja.github.io/portfolio-game/

- Modo leitura normal ou modo jogo (botão Jogar), em português e inglês
- Currículo em PDF para baixar (português e inglês)
- Tour guiado, speedrun com ranking, conquistas e skins
- Rei Gun, dash, chefão, fase Pipeline, sala de servidores e Central de Incidentes (salas secretas)
- Funciona no computador e no celular (botões de toque)

## Contador de visitas (opcional)

O site já está preparado para o [GoatCounter](https://www.goatcounter.com) (gratuito, sem cookies).
Para ativar, crie a conta e escreva o código dela em `index.html`:

```html
<meta name="goatcounter" content="SEU-CODIGO">
```

Sem o código, nenhum script de terceiros é carregado.

Para rodar localmente, abra o `index.html` no navegador.
